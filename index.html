소개

01

화면을 보기 어려운 사람에게도 통하는 인터페이스를 만드는 일에 관심이 있습니다. 시각장애인 보행 보조 앱에서는 카메라가 본 것을 음성 안내로 바꾸는 AI 파트를, 고령자용 스마트홈에서는 한국어 TTS 파이프라인과 대시보드를 맡았습니다.

두 프로젝트 모두 “기술이 되는가”보다 “그 사람이 실제로 쓸 수 있는가”가 어려운 부분이었습니다. 캡스톤에서는 시각장애인 복지관 두 곳을 찾아가 실사용자 테스트를 진행했고, 스마트홈에서는 숫자와 영문이 섞인 안내 문장이 어색하게 읽히는 문제를 전처리 단계에서 해결했습니다.

졸업 캡스톤 디자인/2026

길벗

스마트폰 카메라와 AI로 시각장애인·저시력자의 보행을 돕는 모바일 앱. 실시간으로 장애물을 인식해 회피 방향을 음성과 진동으로 안내합니다.

역할
AI
팀 구성
6명 (AI 2 · BE 2 · FE 2)
규모
커밋 744회

맡은 일

  • 객체 탐지 · 추적 — YOLO 계열 모델로 보행 중 마주치는 장애물을 실시간 인식하고, ByteTrack으로 프레임 간 동일 객체를 추적해 안내가 흔들리지 않도록 했습니다.
  • 보행 가능 영역 분할 — 세그멘테이션 모델로 인도·횡단보도 등 걸을 수 있는 영역을 구분하고, Depth-Anything V2로 추정한 거리 정보를 합쳐 회피 방향을 계산했습니다.
  • 추론 서버 — FastAPI로 모델 서버를 앱과 분리해 구성하고, Spring Boot 백엔드와 연동되도록 API를 설계했습니다.
  • 데이터셋 구축 — AIHub 보행 영상과 Roboflow 데이터셋을 가공해 국내 보행 환경에 맞는 학습 데이터를 만들었습니다.
  • 실사용자 검증 — 성북·노원 시각장애인 복지관에서 사용자 테스트를 진행하고, 탐지 정확도와 안내 방식에 대한 피드백을 모델 기준에 반영했습니다.

제23회 임베디드 소프트웨어 경진대회/2025

CareDian 케어디안

고령자·1인가구를 위한 스마트홈 통합 관리 시스템. 제조사마다 제각각인 기기를 Home Assistant 허브로 묶고, 음성 인터페이스와 mmWave 낙상 감지를 결합했습니다. 카메라를 쓰지 않아 프라이버시 부담이 적습니다.

역할
TTS · 프론트엔드
팀 구성
5명
결과
본선 진출

맡은 일 — 음성 인터페이스

  • 한국어 TTS 파이프라인 구축 — VoxCPM-0.5B를 음성 합성 엔진으로 삼아 Wyoming 프로토콜 서버를 구현하고, Home Assistant의 표준 TTS로 연결해 모든 자동화에서 음성 안내를 쓸 수 있게 했습니다.
  • 텍스트 전처리로 발음 품질 확보 — 기기 상태 메시지에는 숫자와 영문이 섞여 있어 그대로 읽히면 어색합니다. Kiwi로 형태소를 분석하고 KSS로 문장을 나눈 뒤, num2words와 g2p-en으로 숫자와 영문을 한국어 발음으로 변환해 자연스럽게 들리도록 했습니다.
  • 음성 출력 규격 정리 — 16kHz / mono / 16bit WAV로 출력 포맷을 통일해 Home Assistant 기기 전반에서 동일하게 재생되도록 했습니다.
  • 자녀 음색 TTS — 고령 사용자가 안내를 더 편하게 받아들이도록 익숙한 목소리로 합성하는 방식을 적용했습니다.

맡은 일 — 프론트엔드

  • Lovelace 대시보드 구성 — 기기 제어, 낙상 알림, 에너지 사용 현황을 한 화면에서 볼 수 있도록 Home Assistant 대시보드 UI를 설계했습니다.
  • 접근성 우선 화면 — 복잡한 설정이 진입장벽이 되지 않도록, 고령 사용자가 바로 이해할 수 있는 수준으로 화면을 단순화했습니다.
